## 🌟 THE FIVE BINDING STANDARDS

### 1. ETHICAL DESIGN & ANTI-ADDICTION ⭐⭐
```
REJECTS: Facebook's exploitation model
REQUIRES: Societal Betterment Matrix ≥ 15/25
PROHIBITS: Infinite scroll, streaks, FOMO, social comparison, 
		   badges, dark patterns, child exploitation
PROTECTS: User wellbeing, autonomy, trust
FILE: TUBIE_TOOLS_ETHICAL_DESIGN_AND_ANTI_ADDICTION_STANDARD.md
```

### 2. ACCESSIBILITY & SOCIAL IMPACT ⭐⭐
```
SERVES: Disabled community (blind, deaf, motor disabled, etc.)
REQUIRES: WCAG 2.1 Level AA compliance
ENABLES: Keyboard navigation, screen reader, zoom, contrast
PROTECTS: All users, especially vulnerable populations
FILE: TUBIE_TOOLS_ACCESSIBILITY_AND_SOCIAL_IMPACT_STANDARD.md
```

### 3. TEST-FIRST CODE GENERATION
```
REQUIRES: Tests before code merge
MINIMUM: 80% coverage for new code
TYPES: Unit, integration, external connectivity tests
FILE: TEST_FIRST_CODE_GENERATION_POLICY.md
```

### 4. MSTEST FRAMEWORK ONLY
```
REQUIRES: MSTest (not xUnit, not NUnit)
MANDATORY: [TestClass], [TestMethod], [Description]
PATTERN: AAA (Arrange-Act-Assert)
FILE: MSTEST_ENFORCEMENT_STANDARD.md
```

### 5. NUGET PACKAGE VERIFICATION
```
REQUIRES: Upstream dependencies verified
PROCESS: dotnet restore must succeed
GOAL: Zero broken builds, zero version conflicts
FILE: NUGET_VERIFICATION_STANDARD.md
```
